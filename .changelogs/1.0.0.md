## First Release of DH Retro

### World generation
- Fixed generation stalling and permanent ring-shaped LOD holes: failed tasks now free their slot
- Up to 3 world gen tasks per thread, kept under Forge's 1000 force-loaded chunk limit
- World gen tasks no longer hold a shared DH worker thread while waiting on the server
- Missing sections are re-checked every 30 seconds, and nearby holes jump ahead of far requests when the queue is full
- Fixed chunks staying force-loaded forever when a chunk failed to generate

### Server TPS protection
- DH's own server-thread time now counts toward the server health check
- One slow tick no longer pauses generation for 5 seconds
- The progress message says why generation is paused

### Performance
- Faster block and biome lookups while building LODs
- Less busy-waiting in the chunk update queue
- Cached dirt color, player chunk position and fog checks

### Fixes
- Fixed no mixins applying outside of a dev environment
- Fixed Angelica mixin exclusions not matching
- HodgePodge compat is now registered on both client and server
- Fixed an NPE in beacon culling
- Fixed a crash when lwjgl3ify initializes OpenGL late
- GregTech: handle blocks with empty texture arrays
- Ignore right-clicks on air, which reported the wrong block position

### Removed
- The upstream auto-updater
